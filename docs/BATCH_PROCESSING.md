# 批处理文献（1.9.0）

在 Zotero 文献库按 Ctrl / Shift 多选条目或 PDF，右键打开带 SI 图标的“SI 文献助手”，或从工具菜单打开 SI。工作台显示待处理列表，可勾选、全选或取消全选。修改文献库选择后，点击“读取文献库当前选择”重新带入。

在同一个“总结类型”下拉框选择文献总结、表格总结或文献高亮标记，然后点击批量按钮。每篇分别生成笔记或原生 PDF 高亮，并独立保存历史记录、文献关联与耗时。表格总结是逐篇生成表格，不是跨文献合并对比表。

队列逐篇执行。开始后冻结本次条目 ID、模型配置及提示词；期间切换文献库选择不会改变正在执行的队列。父条目与其同一 PDF 同时选中时只处理一次；不同 PDF 附件分别处理。缺失附件、条目已删除或单篇失败都会记录结果，继续下一篇。

“完成当前文献后停止”会让正在执行的一篇正常结束，剩余条目标为未执行；关闭进度弹窗不停止任务。关闭工作台后，本篇完成后停止后续队列。退出 Zotero 会中断任务，不提供自动断点续跑。

结果区按篇折叠显示，列表标注完成、失败、重复跳过或未执行。重试时重新勾选需要处理的文献；总结重试会生成新的笔记，高亮沿用已有去重规则。

验证：`node tests/batch.js` 覆盖三种操作、顺序执行、失败隔离、PDF 去重、配置快照、完成当前篇后停止及队列锁释放。`node tests/dashboard.js` 覆盖选择列表、全选/取消、批处理结果与停止按钮；其余高亮、错误处理和冒烟测试同时通过。尚未在真实 Zotero 文献库中执行批处理实测。
